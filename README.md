# alita-github-demo

一个最小示例项目，用来演示「GitHub部署发布」技能：本地项目 → git init → 首次提交 → 关联远程仓库 → 推送到 GitHub。

## 目录结构

```
alita-github-demo/
├── README.md
├── .gitignore
├── src/
│   └── hello.py
└── notes/
    └── deploy-checklist.md
```

## 说明

- `src/hello.py`：一个零依赖的小脚本，跑起来输出问候语。
- `notes/deploy-checklist.md`：发布前的自查清单。

## 本地运行

```bash
python src/hello.py
```
